# ЕЯЗиС — Естественно-языковые системы

Учебные лабораторные работы на Python: информационный поиск, определение языка, реферирование, машинный перевод, обработка и распознавание речи.

Проверенное окружение: **Windows, Python 3.12.6**. Каждая лабораторная содержит собственную инструкцию, зависимости и проверки.

## Общий веб-интерфейс

Дважды нажмите **[start_web.cmd](start_web.cmd)** в корне проекта: откроется локальное
приложение с отдельным рабочим пространством каждой лабораторной №1–9.
Подключены реальные расчёты, загрузка файлов, графики, аудио, история и экспорт.
Сборка и зависимости на текущем компьютере подготовлены.
Установка после клонирования и подробности: [webapp/README.md](webapp/README.md).
Прежние CLI и окна Tkinter также доступны.

## Начало работы

```powershell
git clone https://github.com/xarturhax/EYAZIS.git
cd EYAZIS
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r lab9/requirements.txt
.venv/Scripts/python.exe -B -m lab9.tools.download_models
.venv/Scripts/python.exe -B -m lab8.tools.download_voices
.venv/Scripts/python.exe -B -m lab9
```

Пример выше устанавливает №9 и используемый ею синтез из №8. Для других работ устанавливайте зависимости из их README.
Пакеты №2–4, №8–9 запускаются из корня командой `python -B -m labN`; №1 — `python lab1/main.py`.
В PyCharm выберите интерпретатор созданного окружения.

Большие скачанные модели, Praat, виртуальное окружение, node_modules, кэши, логи, рабочие базы и личные записи в Git не включены.
Скрипты установки моделей и инструкции сохранены. Поэтому после клонирования требуется подготовить модели нужной лабораторной.
Готовые демонстрационные отчёты, синтетические WAV, небольшие корпуса и сведения об их источниках включены в репозиторий.
