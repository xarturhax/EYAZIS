# Предложение нового интерфейса

Откройте `index.html` в браузере. Установка зависимостей и запуск сервера не нужны.

Это интерактивная дизайн-концепция, а не перенос функций лабораторных.
Работают переходы в девять рабочих пространств, поиск и фильтры, смена темы,
разделы эксперимента/материалов/справки и ссылки на существующие результаты.
Кнопки вычислений отключены и явно обозначены как неподключённые.
Локальные материалы №5–7 доступны на этом компьютере; после клонирования их может не быть.

## Предлагаемое приложение

Один локальный Python-сервер и одна главная страница с отдельными адресами лабораторных.
Общий дизайн, боковая навигация, состояние длительных операций, просмотр результатов
и экспорт. Сервер слушает только 127.0.0.1; модели загружаются по необходимости.
Микрофон включается явной кнопкой. Исходные данные и пользовательские оценки сохраняются.

Для сервера предлагается FastAPI, для рабочего интерфейса — React с TypeScript.
FastAPI умеет отдавать статические файлы и результаты операций, поэтому собранный
интерфейс можно обслуживать тем же процессом: отдельный Node-сервер при обычном
запуске не нужен. Node потребуется для разработки и сборки интерфейса.

Использовать существующие domain/application/infrastructure через адаптеры представления.
Сначала общая оболочка и полная лабораторная №1, затем №2–4, №5–7 и №8–9.
Перенос каждой работы включает её реальные сценарии, загрузку/сохранение данных,
ошибки, отмену длительных операций и проверку эквивалентности с текущей логикой.
Перенос микрофона и голосовых команд требует отдельной проверки жизненного цикла
аудиопотока; браузерный интерфейс может управлять существующим Python-аудиовходом.

Будущий запуск: двойной щелчок по `start_web.cmd`, который выбирает окружение проекта,
запускает сервер и открывает браузер. Такой файл пока не реализован.

Альтернатива: PySide6/Qt Quick для отдельного настольного окна. Это другой полноценный
слой представления, который тоже потребует переноса сценариев; для данного проекта
предпочтителен браузер с его существующими HTML-отчётами и аудиоплеерами.
