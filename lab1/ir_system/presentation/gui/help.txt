Вариант 36: Интернет, английский язык, вероятностный модуль отбора BM25.

1. «Коллекция»: загрузите демо или HTTP(S) URL английской страницы.
   HTML/plain text до 2 MiB, таймаут 15 секунд; JavaScript не выполняется.
2. «Поиск»: введите английский запрос. BM25 сортирует по убыванию ранга.
   Двойной щелчок открывает URL. «Текст» показывает сохранённый документ.
3. «Оценка качества» → «Разметка»: выберите запрос и оцените ВСЕ документы.
   0 — нерелевантно, 1 — частично, 2 — полностью. Сохранение сразу.
   Выделите строки и нажмите кнопку или клавишу 0/1/2.
4. «Оценить запрос» / «Оценить все» → «Результаты»: значения с пояснениями.
   Выберите средние или отдельный запрос. Каждый допустимый запрос имеет равный вес.
   Запросы без релевантных документов (R=0) исключаются по РОМИП, а не дают нулевой балл.
5. «Графики»: выберите тип диаграммы и средние/отдельный запрос.
   Метрики — столбцы со значениями. Полнота–точность — кривая TREC с 11 порогами.
   Сравнение запросов — цветовая таблица всех шести метрик с числами.
   Панель под графиком позволяет масштабировать и сохранять рисунок.
6. «Экспорт отчёта» создаёт HTML с пояснениями, SVG/PNG, JSON и CSV.

Precision — доля релевантных среди найденных.
Recall — доля найденных среди всех релевантных в коллекции.
AP — среднее точностей на релевантных позициях с учётом пропусков; MAP — среднее AP.
P@5 / P@10 — число релевантных в первых 5 / 10, делённое на 5 / 10.
Знаменатели фиксированы даже при короткой выдаче.
R-precision — точность первых R позиций, R — число релевантных в коллекции.
Оценки 1 и 2 обе считаются релевантными.

На PR-графике X — полнота, Y — точность. Синяя линия: 11 значений TREC,
максимум точности при полноте не ниже каждого порога; недостигнутый порог даёт 0.
Оранжевый пунктир: фактические значения по позициям выдачи для одного запроса.
RIRES упомянута, но не определена в предоставленном PDF; рассчитывается TREC.

Методика: 2004_romip_metrix.pdf. Подробнее — README.md и docs/ROMIP_METRICS.md.
Ранг BM25 не является вероятностью и не заменяет экспертную оценку качества.
