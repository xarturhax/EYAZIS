# Лабораторная работа №2 — вариант 36

Распознавание **английского и испанского языка в PDF**:
короткие слова, статистический алфавитный метод, нейросеть.
Приложение работает локально; интернет нужен только для установки зависимостей
и повторной загрузки исходников демо, если они удалены.

## Запуск в PyCharm

Выберите интерпретатор проекта `.venv/Scripts/python.exe` (Python 3.12+).
Откройте `lab2/main.py` и нажмите Run. Рабочая папка может быть корнем проекта или `lab2`.

Из корня проекта:
```powershell
.venv/Scripts/python.exe -m pip install -r lab2/requirements-lock.txt
.venv/Scripts/python.exe -B -m lab2
```

`requirements-lock.txt` фиксирует проверенные версии; `requirements.txt` задаёт допустимые диапазоны.
Tkinter входит в стандартную Windows-установку Python: при отсутствии установите компонент Tcl/Tk.

1. **Демо-коллекция** — загрузить 48 готовых одностраничных PDF.
2. **Обучить и сравнить** — построить профили и обучить нейросеть на 32 PDF, проверить на 16.
3. Вкладка **Результаты** — языки, точность и среднее время.
   Выберите строку для оценок/объяснений; двойной щелчок открывает исходный PDF.
4. Вкладка **Графики** — сравнение точности и времени.
5. **Экспорт отчёта** — HTML, JSON, CSV, SVG/PNG и схема алгоритма.
6. **Печать** — открыть отчёт в браузере; кнопка «Распечатать» или Ctrl+P,
   в том числе «Сохранить в PDF». Прямая отправка на физический принтер не выполняется автоматически.
7. **Справка / F1** — инструкция, смысл метрик и ограничения.

Готовый отчёт: [reports/demo/report.html](reports/demo/report.html).
Описание для защиты: [docs/REPORT.md](docs/REPORT.md).
Данные и происхождение: [data/demo/README.md](data/demo/README.md).

## Свои документы

В «Коллекции» выберите роль `train` или `test` и эталонный язык `en`, `es` или `?`,
затем «Добавить PDF». Для train язык обязателен. Результат всегда получается из текста;
эталонные метки test используются только при оценке качества.
Тест с неизвестным языком распознаётся, но не входит в accuracy/F1.

Потребуются train-документы обоих языков. Методичка указывает 20–120 КБ:
в проекте принят объём нормализованного UTF-8 текста **20–120 KiB на язык**.
Демо соответствует диапазону и на язык, и суммарно. Для меньшего пользовательского корпуса
показывается предупреждение, а не запрет учебного эксперимента.
Для сравнения времени используйте тестовые тексты одинаковой длины, например одну страницу A4.

«Сохранить список» создаёт JSON-манифест. В нём можно указать `source_id`:
для всех отрывков одной книги он должен совпадать. Совпадение источника между train/test
и точные дубликаты нормализованного текста запрещены.
Без source_id программа предупреждает, что независимость источников не проверена полностью.
Похожие или перефразированные тексты автоматически не обнаруживаются.

Минимальная запись манифеста:
```json
{
  "schema": 1,
  "documents": [
    {
      "path": "pdf/english_training.pdf",
      "split": "train",
      "language": "en",
      "source_id": "book-a",
      "source_url": "https://example.org/book-a",
      "title": "English training"
    }
  ]
}
```
Этот пример показывает структуру записи; для запуска добавьте испанский train и test.
Пути отсчитываются от манифеста. Добавление/удаление файлов и изменение параметров
сбрасывают старые результаты. Сохранённый HTML содержит абсолютные ссылки:
после переноса проекта повторно выполните экспорт.

## Командная строка

```powershell
.venv/Scripts/python.exe -B -m lab2 evaluate --output lab2/reports/local
.venv/Scripts/python.exe -B -m lab2 evaluate --manifest my_collection.json --seed 36 --repetitions 5
.venv/Scripts/python.exe -B -m lab2 evaluate --pdf "C:/texts/document.pdf" --output lab2/reports/custom
```

В последнем примере обучение берётся из демо, вместо его test используются указанные PDF
без эталонных меток. Нейросеть обучается при каждом эксперименте; pickle-файлы не загружаются.
Лог неожиданных ошибок: `lab2/logs/lab2.log`, ротация 1 MB / 2 резервные копии.
Стандартные ошибки PDF показываются сообщением с именем файла.

## Алгоритмы

- **Короткие слова:** NFC/casefold, Unicode-токены, длина до 5, частота в языковом
  train-корпусе не менее 4, аддитивное сглаживание 0.5.
  Решение — минимальная средняя отрицательная log-вероятность.
  Стоп-слова и диакритика сохраняются.
- **Алфавитный:** нормированные частоты 33 одиночных букв латиницы с испанскими
  дополнениями, минимальное L1-расстояние до обучаемого языкового профиля.
  Это явно выбранный статистический вариант метода: проверка только набора букв
  не различает EN/ES надёжно.
- **Нейросеть:** символьный TF-IDF (2–4), до 3000 признаков, MLP с 32 нейронами
  скрытого слоя, ReLU, L-BFGS, alpha=0.01, seed=36.
  Train-PDF делятся на непересекающиеся фрагменты до 80 слов, хвосты короче 10 слов
  исключаются. Test не участвует в словаре признаков, IDF и обучении.

Настройки алгоритмов собраны в `domain/models.py:Settings`.
GUI позволяет менять seed и количество повторов измерения времени.
При недостатке данных возможен отказ «Не определён». Модель не является универсальным
детектором третьих языков, особенно на латинице; вероятности MLP не калиброваны.


15 тестов: ручные расчёты, Unicode, отказы, ошибки PDF, предотвращение утечки данных,

фоновое выполнение, таблицу, график, экспорт и сброс результата.
Mypy проверяет производственный код и инструмент подготовки данных, исключая тесты.

## Ограничения

- Только PDF с текстовым слоем; OCR не реализован. Защищённые паролем PDF требуют снятия пароля.
- Ограничения: 20 MiB, 100 страниц, 1 млн извлечённых символов на файл.
- Успешное чтение текстового слоя не гарантирует отсутствие ошибок OCR или порядка чтения.
- Отмена проверяется между этапами/повторами; текущий fit завершается до отмены.
- Демо состоит из литературы, по одному тестовому произведению на язык:
  100% на этих 16 отрывках не означает 100% на других жанрах.
- Размер источника, разрядность PDF, длина текста и время модели — разные величины.
