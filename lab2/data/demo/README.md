# Учебная коллекция

32 обучающих и 16 тестовых одностраничных PDF A4, около 2400 символов каждый.
Каждое из шести произведений даёт восемь отрывков. Деление по книгам и авторам,
а не случайное перемешивание отрывков. Шапки, лицензии и эталонные метки не входят
в извлекаемый текст PDF.

Исходники Project Gutenberg и их лицензионные уведомления сохранены в sources/.
Сведения об авторах, оригинальные URL и SHA-256 файлов — provenance.json.
Позиции отрывков, языки и роли — manifest.json.
Разметка взята из языка оригинального произведения и проверена по метаданным источника.

Train: Carroll/Austen (EN), Cervantes/Pérez Galdós (ES).
Test: Conan Doyle (EN), Alarcón (ES).
В издании Alarcón #29506 английское введение, NOTES и словарь исключены.
Отбор — позиции 10%,20%,...,80% основного нормализованного текста, по 2400 символов
с коррекцией границ до пробела; без подбора удачных фрагментов по результатам моделей.

Воспроизведение из корня:
```powershell
.venv/Scripts/python.exe -B -m lab2.tools.build_demo
```
Если sources/ уже заполнен, сеть не используется. Иначе загружаются оригиналы по HTTPS.
Повторная загрузка будущих редакций источников может изменить текст; для точного
повторения используйте приложенные оригиналы и контрольные суммы.
Стандартный запуск GUI/CLI не загружает интернет-страницы.

Коллекция является учебной, не промышленным бенчмарком.
Одна тестовая книга на язык ограничивает представительность оценки.
