# Лабораторная работа №3 · Вариант 27

Автоматическое реферирование английских и испанских документов по медицине
и художественной критике. Реализованы алгоритм методички **TF-IDF × позиции**
и сравнительный **TextRank**. OSTIS заменён по согласованию с пользователем.

## Запуск

Из корня проекта в PowerShell:

```powershell
.venv\Scripts\python.exe -m pip install -r lab3\requirements.txt
.venv\Scripts\python.exe -B -m lab3
```

Зависимости и обе языковые модели уже установлены в текущем окружении.
После установки работа выполняется локально, сеть при реферировании не нужна.
Также можно запустить `lab3/main.py` из корня или `main.py` из папки `lab3`.

В интерфейсе нажмите **Демо → Сравнить**. Выберите документ в таблице,
затем метод просмотра. Выбранные предложения подсвечиваются в исходном тексте.
Вкладки содержат реферат с ключевыми словами, веса всех предложений и сравнение.
Предложений по умолчанию 10, ключевых слов 10; допустимо от 1 до 100.

**Сохранить отчёт** создаёт HTML, JSON, CSV и копии входных текстов.
**Печать** открывает HTML в браузере; кнопка в отчёте вызывает диалог печати,
где можно сохранить PDF. Физический принтер не проверялся.
Справка доступна по F1.

## Свои документы

Поддерживаются UTF-8 TXT и PDF с текстовым слоем. Язык и область задаются явно:
`en` / `es`, `medicine` / `art`. Можно добавить файлы через интерфейс
или открыть JSON-манифест. Пути в манифесте разрешаются относительно самого JSON.

```json
{
  "schema": 1,
  "documents": [
    {
      "path": "texts/article.txt",
      "language": "es",
      "domain": "medicine",
      "title": "Название статьи",
      "url": "https://example.org/article",
      "attribution": "Автор, издание, год",
      "license": "Условия использования"
    }
  ]
}
```

В TXT отделяйте абзацы пустой строкой; одиночные переносы считаются вёрсткой.
Символьные позиции относятся к нормализованному входному тексту.
PDF-блоки приближённо принимаются за абзацы: проверьте колонки, колонтитулы
и переносы. Для точного воспроизведения формул предпочтителен подготовленный TXT.
Сканированные PDF, файлы с паролем и файлы без буквенного текста диагностируются.

Корпус IDF строится отдельно для каждого языка **по всем загруженным документам**,
включая реферируемые. Для единственного документа IDF всех терминов равен нулю:
это следствие формулы методички, приложение сообщает об этом.
Добавьте несколько разных документов обеих областей для каждого языка.
Точные дубликаты нормализованного текста отклоняются.

Ограничения: до 100 документов; один файл до 20 МиБ, PDF до 100 страниц,
нормализованный текст до 200 000 символов, до 1500 предложений в документе.
Для TextRank строится попарный граф, поэтому очень большие тексты требуют иного подхода.

## Корпус и оценка

Демо содержит четыре реальных фрагмента по 12–13 тысяч символов:
по одному для каждого сочетания языка и области.
[Происхождение и лицензии](data/demo/README.md), исходники и SHA-256 сохранены.
Размер 10 страниц A4 в методичке приведён как пример; здесь сопоставимость
определяется числом символов, отношение максимального объёма к минимальному — около 1.08.

`comparison.csv` содержит время предобработки и ранжирования, доли сохранённых слов
и предложений. `results.json` содержит все веса, выбранные индексы, исходные предложения,
параметры, версии и предупреждения. Согласие методов измеряется Jaccard.

**Точность по эталонам не измерена:** эталонных рефератов пока нет.
Файл `expert_assessment-<hash>.csv` — незаполненная форма для оценки человеком
информативности, связности и отсутствия повторов по шкале 1–5.
Анкета привязана к текстам и выбранным предложениям; повторный экспорт её не затирает.
Для изменённых рефератов создаётся новая анкета.

## Проверки и воспроизводимость

```powershell
.venv\Scripts\python.exe -m pip install -r lab3\requirements-dev.txt
.venv\Scripts\python.exe -B -m unittest discover -s lab3/tests -t . -v
.venv\Scripts\python.exe -B -m lab3.tests.gui_smoke
.venv\Scripts\python.exe -m ruff check lab3 --no-cache
.venv\Scripts\python.exe -m ruff format lab3 --check
.venv\Scripts\python.exe -B -m mypy lab3 --config-file lab3/pyproject.toml --no-incremental
```

Для точного окружения Windows/Python 3.12 сохранён `requirements-lock.txt`.
Тесты проверяют ручной расчёт формул, позиции абзацев, порядок предложений,
граничные случаи графа, раздельный IDF, леммы EN/ES, PDF и экспорт.
GUI smoke запускает настоящий скрытый Tk, фоновый расчёт и сохранение отчёта.

Пересобрать демо из сохранённых оригиналов:
`python -B -m lab3.tools.build_demo`.
Отсутствующие оригиналы скачиваются с проверкой HTTPS через системное хранилище
сертификатов Windows (`truststore`).
Лог ошибок: `lab3/logs/lab3.log`.
