# Демонстрационные тексты

Два коротких оригинальных учебных примера на английском, составленных для проверки
приложения: медицина и художественная критика. Это не цитаты из научных статей,
не клинические данные и не эталонный корпус переводов. Примеры предназначены
для быстрой проверки перевода, грамматики и дерева.

Для работы с реальными источниками можно открыть полные английские TXT из
lab3/data/demo/texts/medical_en.txt и art_en.txt. Их атрибуция, лицензии и происхождение
сохранены в lab3/data/demo/README.md и provenance.json.

Real-source excerpts are source_medicine.txt (first 3 sentences) and source_art.txt (first 6 sentences). Their authors, URLs, licenses and SHA-256 are in provenance.json. CLI/build_reports copy the attribution to TXT/HTML exports. Rebuild with python -B -m lab4.tools.build_demo.
