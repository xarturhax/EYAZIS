## Первый этап для пользователя

1. Откройте index.html. Выберите группу «Слова» — 15 элементов.
2. Послушайте контекст и выделение. Слово должно быть целым, без соседнего слова. Исправьте границы при необходимости.
3. Отметьте «Метка и границы верны» только для проверенных элементов.
4. Перейдите в «Фразы-эталоны» — 5 элементов. Проверьте целые фразы и их начала/концы.
5. Нажмите «Скачать разметку JSON». Для этого этапа достаточно 20 подтверждений из 76.
6. Положите segment_review.json в корень EYAZIS или сообщите точный путь к скачанному файлу.

Оставшиеся звуки и слоги можно проверить позднее. Частичный JSON можно загрузить обратно в ту же страницу.
Старые annotation_v1/browser_check.html — служебные и промежуточные материалы, их не использовать для новых оценок.

## Как уточнять границы

Начало/конец вводятся в секундах. Щелчок по графику задаёт начало, Shift+щелчок — конец.
Время ограничено показанным контекстом: для согласного доступен исходный слог, для слова — вся фраза.
Короткий устойчивый участок гласного/фрикативного — намеренный выбор для фонетического банка.
Для согласного из CV-слога начальная граница C/V — только черновой курсор, её особенно важно проверить.
У взрывного согласного оставляйте характерный переход/взрыв, избегая целого гласного.
Неоднозначность границы или добавочный гласный отмечаются в комментарии, а не скрываются.

Усиление +6/+12 дБ меняет только прослушивание. Оригинальные файлы и экспортируемые времена не изменяются.
Сеть и микрофон не используются. На смартфоне приложение не проверялось; рабочая среда — настольный браузер Windows.

```powershell
.venv/Scripts/python.exe -B -m lab5_7.tools.download_alignment_model
.venv/Scripts/python.exe -B -m lab5_7.tools.align_words
.venv/Scripts/python.exe -B -m lab5_7.tools.prepare_review

```

Загрузка модели отдельная, голоса при этом не отправляются в сеть.
Vosk [vosk-model-small-ru-0.22 из официального каталога](https://alphacephei.com/vosk/models) имеет лицензию Apache-2.0.
URL, SHA-256 архива и всех файлов сохраняются в vendor/vosk-model-small-ru-0.22/provenance.json.
Загруженные модели исключены из Git.

Повторная подготовка требует нового --output. Старые проверки не перезаписываются.
Импорт проверяет схему, идентификаторы, диапазоны, SHA-256 исходных WAV и манифест предложений.
Только записи с reviewed=true получают reviewed=yes в data/segments.csv.
Перед обновлением CSV сохраняются предыдущая версия и исходный JSON в reports/local/annotation_import-<hash>/.
Неподтверждённые строки не превращаются в банк, существующие подтверждения не снимаются частичным импортом.
