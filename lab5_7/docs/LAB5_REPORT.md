# Лабораторная №5. Фонетические закономерности

**Состояние: ожидаются записи. Результаты и выводы о голосе не заполнены.**

## ПО и метод

Praat — запись, прослушивание, ручное выделение и циклическое воспроизведение.
Python: SoundFile/libsndfile для WAV PCM_U8/PCM_16, SciPy resample_poly
с антиалиас-фильтром, Parselmouth для F0, Matplotlib для графиков.
Версии записываются в результаты. Praat GUI 7.0.02 и движок Parselmouth 6.1.38
различаются; параметры анализа необходимо зафиксировать.
Исходники не нормализуются автоматически.

Запрос частоты у драйвера и разрядность WAV не доказывают частоту/разрядность
физического АЦП. Если низкая частота не поддерживается, это фиксируется явно.
Цифровой ресемплинг одного исходника обеспечивает сопоставимость произнесения,
но отличается от отдельных записей по методичке.
Квантование подтверждается заголовком WAV, а не типом float-массива в памяти.
