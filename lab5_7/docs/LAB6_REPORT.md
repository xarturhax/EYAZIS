### Реализация доступных аналогов

Sound Forge допускает Pitch Bend (высота связана со временем) и Pitch Shift.
В разрешённой альтернативе используется:
- method=psola: PitchTier/DurationTier Praat и overlap-add.
- method=coupled_contour: переменный ход времени с коэффициентами rate_points;
  повышение скорости повышает F0 и сокращает длительность.
- method=coupled: частный случай постоянного коэффициента по числу полутонов.

Для переменного хода используется dt_out = dt_in / rate(t).
Перед ускорением применяется низкочастотная фильтрация.
Коэффициент 1 сохраняет шкалу времени, 2 удваивает частоты и сокращает время вдвое.
Это воспроизводимые аналоги двух принципов обработки, а не утверждение
о точном повторении закрытых алгоритмов Sound Forge.

rate_points задаются во времени **исходника**, F0 и длительность PSOLA —
во времени переданной на этот шаг записи. Gain задаётся на выходной шкале.
После каждого изменения длительности необходимо заново сопоставить границы слов.
Подъём F0 сам по себе не гарантирует восприятие вопроса:
контуры и акцентные группы проверяются прослушиванием.

Файлы управления содержат настоящие временные точки, параметры и status=READY.
Предусмотренный пустой template не запускается до заполнения.
Метрики используют F0 на голосовых участках; отсутствие F0 не равно 0 Гц.
RMS dBFS описывает цифровой уровень, а не калиброванную акустическую громкость.

Для каждого нужного слова сохранены две стадии:

- Контур F0 плюс 4.5 дБ на выбранном слове; длительность 2.070 с.
- То же плюс растяжение выбранного слова в 1.15 раза: 2.192 с для «Студент»,
  2.143 с для «писал».

Ресинтез выполняется один раз из исходника, затем усиление накладывается на
пересчитанный выходной интервал слова. Новый материал не получается повторным
ресинтезом уже обработанных WAV. Старые вопросительные варианты рядом для сравнения;
их прежние оценки сохранены. Проверены отсутствие клиппинга, пересчёт границ и
коэффициент усиления. Все четыре оценки получены из
`D:/Download_from_Google/lab6_focus_review.json`. Проверены манифест и SHA-256 WAV;
квитанция с исходным JSON, CSV и сводкой:
`reports/local/lab6_question_focus_v1/listening_import-0abc607a593ccbe5/`.

По структурированным ответам совместный критерий выполнен в 4/4 случаях.
В комментариях пользователь всё ещё отмечает скачки внутри «студент» и «писал»,
ощущение обработки и замедление после растяжения. Для первого слова также указано,
что различие с прежним вариантом не ощущается. Эти комментарии сохранены дословно
и не заменены утверждением о выраженном субъективном улучшении. Перемена ответа
о выделении не является доказательством причинного эффекта усиления в слепом тесте:
это последовательное прослушивание одним слушателем с известным замыслом.

Растяжение не повысило ни одну из двух оценок относительно стадии с усилением,
поэтому для итоговой подборки выбрана стадия 2 без дополнительного замедления.
Новых прослушиваний этих четырёх файлов не требуется.

## Итоговая подборка для демонстрации

`reports/local/lab6_selected_examples/index.html` содержит шесть точных копий уже
оценённых WAV: утверждение и вопрос с выделением каждого из трёх слов.
selection.json связывает каждую копию с исходным манифестом и неизменённым JSON оценок.
По всем шести примерам заново построены осциллограммы, спектрограммы, F0 и RMS.

лучшими имеющимися оценками и меньшим числом преобразований при равенстве оценок.
