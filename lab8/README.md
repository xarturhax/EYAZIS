# Лабораторная №8 · Вариант 8

**Синтез французской речи для сочинений по литературе.**
Локальный Piper с двумя голосами: Siwis и Tom.
Голосовые записи пользователя для этой работы не нужны.

## Запуск

Из корня проекта:

```powershell
.venv\Scripts\python.exe -B -m lab8
```

Зависимости и оба голоса в текущем окружении уже установлены.
Также работают lab8/main.py из корня и main.py из папки lab8.

1. Введите французский текст, откройте UTF-8 TXT или вставьте из буфера.
2. Выберите голос, темп и громкость.
3. Нажмите **«Читать»**: синтез выполняется в фоне, затем начинается воспроизведение.
4. **«Стоп»** останавливает WAV или отменяет оставшиеся фрагменты синтеза.
5. **«Повторить»** воспроизводит готовый результат.
6. **«Сохранить WAV»** создаёт также Unicode-текст, JSON параметров и HTML-отчёт.

Есть два оригинальных учебных сочинения-примера, справка F1.
Изменение текста/параметров останавливает чтение и сбрасывает старый результат.

## Параметры

- Голос: Siwis (22 050 Гц) или Tom (44 100 Гц), французский France.
- Темп: 0.5–2.0×. Это коэффициент модели, не слова в минуту.
  Фактическая длительность измеряется; точная обратная пропорция не обещается.
- Громкость: 0–100%. При 0% тишина создаётся намеренно.
- До 5000 символов. Длинный текст разбивается по пунктуации/пробелам,
  слова и французские диакритические знаки сохраняются.
- WAV: mono PCM16. Перед записью применяется коэффициент запаса 0.98.
- Отмена синтеза проверяется между фрагментами/предложениями;
  текущая операция модели сначала завершается.
- Воспроизведение идёт через стандартное устройство Windows.

Синтез выполняется локально, сеть нужна только при установке голосов.
Встроенный SAPI5 был проверен: доступны Irina ru-RU и Zira en-US,
французского голоса нет. Методичка допускает нейросетевые библиотеки,
поэтому выбран Piper; языковые компоненты Windows не изменялись.

## Консоль

```powershell
.venv\Scripts\python.exe -B -m lab8 voices
.venv\Scripts\python.exe -B -m lab8 synthesize --input lab8\data\essai_hugo.txt --voice siwis --speed 1 --volume 0.8 --output lab8\reports\custom.wav
.venv\Scripts\python.exe -B -m lab8 synthesize --text "La littérature nous invite à réfléchir." --voice tom --output lab8\reports\lecture.wav --play
```

Синтез без --play создаёт WAV без включения динамиков.
Существующие WAV не перезаписываются: выберите новое имя.
GUI-кэш находится в work/ и не заменяет экспортированные результаты.
Ошибки записываются в logs/lab8.log с ротацией.

[Готовые примеры с аудио](reports/demo/index.html) · [Отчёт для защиты](docs/REPORT.md)

Восемь примеров показывают оба голоса, замедление, ускорение, уменьшение громкости
и нулевую громкость. Для каждого сохранены WAV, TXT, JSON и HTML.
Слуховая анкета listening.csv оставлена пустой: оценки естественности не выдумываются.

## Установка на другом компьютере

Windows, Python 3.12:

```powershell
python -m pip install -r lab8\requirements.txt
python -B -m lab8.tools.download_voices
python -B -m lab8
```

Для проверенного окружения есть requirements-lock.txt (8 runtime-дистрибутивов).
Модели скачиваются отдельно (~127 МБ) по закреплённой ревизии:
5041a7a49ae5b3a0f30e6837769eb03fdbb231bd.
Локальные SHA-256 проверяются перед первой загрузкой каждого голоса.

Piper распространяется под GPL-3.0; карточки голосов сохранены в models/.
В MODEL_CARD Siwis указаны данные CC BY 4.0, Tom — данные AGPLv3.
Общий ярлык лицензии репозитория голосов не подменяет эти отдельные карточки.
Источники: [Piper](https://github.com/OHF-Voice/piper1-gpl),
[Siwis](https://huggingface.co/rhasspy/piper-voices/tree/main/fr/fr_FR/siwis/medium),
[Tom](https://huggingface.co/rhasspy/piper-voices/tree/main/fr/fr_FR/tom/medium).

Тесты создают настоящий французский звук, но вызовы динамиков и пользовательского

GUI повторно использует TaskRunner из lab2/presentation/tasks.py:
сохраняйте структуру всего репозитория.
