### Лабораторная №8 — реализована, вариант 8 (2026-10-25)

Текущая задача: №8, французский синтез, сочинения по литературе.
№5–7 пользователь явно отложил до другого раза; голос сейчас не запрашивать.
№9 пока не начинать без отдельного задания.

Пакет lab8/, запуск .venv/Scripts/python.exe -B -m lab8.
Зависимости и два голоса уже установлены.
GUI: французский текст / UTF-8 TXT / буфер, Siwis или Tom,
темп 0.5–2.0×, громкость 0–100%, Читать/Стоп/Повторить/Сохранить.
Примеры: оригинальные учебные сочинения о Hugo и басне.
Инструкция lab8/README.md, описание для защиты lab8/docs/REPORT.md.
Готовые WAV/HTML: lab8/reports/demo/index.html (8 примеров).

Решение по движку: SAPI5 проверен через pyttsx3, доступны только Irina ru-RU
и Zira en-US. Французского голоса нет. Выбран разрешённый методичкой Piper,
системные языковые компоненты Windows не менялись.
Piper 1.8.0, ONNX Runtime 1.31.0, NumPy 2.5.3.
Голоса fr_FR-siwis-medium (22050 Гц) и fr_FR-tom-medium (44100 Гц),
HF rhasspy/piper-voices revision 5041a7a49ae5b3a0f30e6837769eb03fdbb231bd.
models/voice/MODEL_CARD и manifest.json сохранены, SHA-256 проверены.
Карточки указывают данные Siwis CC BY 4.0 и Tom AGPLv3; Piper GPL-3.0.
Не заменять отдельные карточки общим MIT-ярлыком репозитория.
requirements-lock.txt: 8 runtime-дистрибутивов Windows/Python 3.12.
Установка голосов отдельно: python -m lab8.tools.download_voices.

Архитектура domain/application/infrastructure/presentation, Protocol синтезатора
и проигрывателя. Однопоточный worker через lab2.presentation.tasks.TaskRunner,
Tk только в главном потоке. Модели загружаются лениво и используются последовательно.
Голосовой пользовательский материал не требуется.
Темп задаёт length_scale=1/speed, шумы модели 0 для воспроизводимости,
цифровая громкость и запас 0.98 применяются к нормализованным предложениям.
5000 символов, части ~300 символов без потери слов; Unicode/NBSP поддержаны.
WAV mono PCM16, максимум 10 минут. Отмена проверяется между частями.
Stop немедленно останавливает winsound и запрещает автовоспроизведение
завершающегося синтеза. Старый результат сбрасывается при изменении текста/настроек.

Экспорт: WAV, Unicode TXT, JSON и HTML с корректным URL имени WAV.
Защищены от перезаписи все четыре файла; неверное расширение отклоняется.
Временные WAV — work/, настройки/метрики и исходный текст — в экспорте.
Фоновый синтез не включает динамики: воспроизведение вызывается отдельно.
CLI synthesize без --play только пишет WAV. Ошибки — logs/lab8.log.
