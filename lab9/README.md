# Лабораторная №9 — вариант 8

Распознавание **французской речи**, предметная область — **сочинения по литературе**.
Офлайн Vosk распознаёт речь, настраиваемые команды управляют чтением литературного сочинения из лабораторной №8.
Tkinter показывает промежуточный текст, окончательную фразу, решение и уведомление о действии.
Английский ASR добавлен как дополнительный язык для осмысленной проверки переключения модели; французский остаётся языком варианта и синтеза.

## Запуск

Из корня проекта в PowerShell:

```powershell
.venv/Scripts/python.exe -B -m lab9
```

Также: `lab9/main.py` из корня или `main.py` из папки lab9.
Зависимости и обе модели Vosk уже установлены в текущем окружении. Сети при распознавании и синтезе не требуется.
Переустановка:

```powershell
.venv/Scripts/python.exe -m pip install -r lab9/requirements.txt
.venv/Scripts/python.exe -B -m lab9.tools.download_models
.venv/Scripts/python.exe -B -m lab8.tools.download_voices
```

Для воспроизведения проверенного Windows-окружения: `lab9/requirements-lock.txt` (24 runtime-пакета, Python 3.12.6).
Модели не входят в pip-зависимости. Кэш Vosk: `lab9/models/`; голоса Piper: `lab8/models/`.

## Работа в окне

1. Введите/вставьте французское сочинение, откройте TXT UTF-8 или используйте пример о Гюго и басне. Пустая строка разделяет абзацы; максимум 5000 символов.
2. Выберите язык ASR `fr`. Кнопка «Микрофоны» обновляет устройства, но не начинает запись. Выберите нужный вход.
3. Во вкладке команд задайте фразы и соответствующие операции; строки можно добавить, изменить, отключить и удалить. Нажмите «Сохранить настройки».
4. Нажмите «Включить микрофон», произнесите целую команду и выдержите паузу для окончания фразы. Система автоматически выполнит разрешённую операцию и покажет уведомление.
5. Кнопка «Прекратить распознавание» закрывает вход. Результат незавершённой фразы при остановке не выполняется.
6. Без микрофона нажмите «Проверить WAV»: получите текст и решения **без выполнения действий**. Пример: `lab9/reports/demo/audio/tom_read.wav`.
7. Журнал можно экспортировать в HTML/JSON/CSV; HTML печатается браузером. Справка — F1.

Вход микрофона **не записывается в аудиофайл**, но распознанный текст остаётся в журнале сеанса; экспорт запускается пользователем.
Промежуточные результаты показываются, операции выполняются только по завершённым фразам.
Снятый флажок «Выполнять команды» оставляет распознавание и уведомления в режиме проверки.

| Фраза по умолчанию | Операция |
|---|---|
| lecteur commence | Прочитать выбранный абзац |
| lecteur stop | Остановить чтение |
| lecteur suivant | Выбрать следующий абзац |
| lecteur précédent | Выбрать предыдущий абзац |
| lecteur répète | Повторить выбранный абзац |
| lecteur plus vite | Увеличить темп на 0.1× |
| lecteur plus lentement | Уменьшить темп на 0.1× |

Переход сам по себе не запускает чтение. Изменение темпа применяется к следующему синтезу, диапазон 0.5–2×.
Есть ручные кнопки чтения/навигации/остановки, два голоса Siwis/Tom и громкость.

Французская команда начинается с `lecteur`, английская — с `reader`; всего 2–12 слов.
Команда совпадает с распознанной фразой **целиком** после удаления регистра, диакритики и пунктуации.
Упоминание «lecteur commence» внутри более длинного предложения не выполняет действие.
По умолчанию средняя оценка Vosk должна быть ≥0.75, каждое слово ≥0.55; оценки обязаны покрывать всю фразу.
Это эвристика, а не калиброванная вероятность правильности. Порог меняется ползунком и сохраняется в JSON.
Защита от повторения одной операции — 1.2 с; STOP исключён из задержки. Интервал задаётся в JSON `cooldown_seconds`.
Неизвестные, отключённые и неуверенные фразы показываются с причиной отказа.

**Режим аудио:** по умолчанию микрофон приостановлен на время синтеза и воспроизведения.
Для команды STOP во время воспроизведения включите «Слушать при чтении (наушники)» и используйте наушники.
Акустическое эхоподавление не реализовано: с динамиками возможна реакция на собственное чтение.
Во время синтеза вход приостановлен в обоих режимах; ручная кнопка остановки работает всегда.
Подготовленный голос может занимать время; выполняющийся фрагмент ONNX отменяется по завершении вычисления.

## CLI и воспроизводимые проверки

```powershell
.venv/Scripts/python.exe -B -m lab9 recognize --input lab9/reports/demo/audio/tom_stop.wav --language fr --output lab9/reports/manual_test
.venv/Scripts/python.exe -B -m unittest discover -s lab9/tests -v
.venv/Scripts/python.exe -B -m lab9.tests.gui_smoke
.venv/Scripts/python.exe -B -m lab9.tools.build_demo
.venv/Scripts/python.exe -B -m ruff check lab9 --no-cache
.venv/Scripts/python.exe -B -m ruff format lab9 --check
.venv/Scripts/python.exe -B -m mypy lab9 --config-file lab9/pyproject.toml --no-incremental
```

CLI `recognize` всегда тестовый: операции не исполняются, даже при ACCEPTED в журнале.
`devices` только перечисляет устройства. WAV: до 50 МиБ, до 180 с; используется первый канал, ресэмплинг в 16 кГц, mono PCM16.
Фоновый микрофон работает с частотой устройства. Переполнение буфера или ошибка PortAudio останавливает распознавание с сообщением.

Демонстрация: [reports/demo/index.html](reports/demo/index.html), исходные результаты: [metrics.json](reports/demo/metrics.json).
Повторный `build_demo` использует WAV с проверкой эталонной фразы, голоса и SHA-256. Если изменили команды, сохраните прежнюю папку demo под другим именем перед пересборкой.
При сбое первой сборки неподтверждённые WAV тоже нужно сохранить отдельно; скрипт не присваивает старой записи новый эталон.
Журнал ошибок: `lab9/logs/lab9.log`, временный синтез: `lab9/work/`.

## Что проверено и что остаётся

25 unittest, отдельный скрытый GUI smoke, Ruff и mypy.
В тестах микрофон и выход звука заменены имитацией; реальные Vosk и Piper проверены на синтетических файлах.

На 23 синтетических примерах: **7/14 принятых команд**, **0/9 ложных активаций**, нормализованный WER **7/128 ≈ 5.47%**.
Siwis: 2/7, Tom: 5/7; четыре верно распознанные короткие команды отклонены порогом уверенности, три содержат ошибки распознавания.
Это небольшая техническая демонстрация, а не измерение качества человеческой речи.
Проверка реального микрофона, французского произношения и задержки автоматической реакции остаётся ручной.
Понижение порога может увеличить число принятых команд вместе с риском ошибок; параметры не подгонялись для красивого результата.
