# ЕЯЗиС в браузере

Современный общий интерфейс для лабораторных №1–9 на основе одобренного макета.
React/TypeScript показывает формы и результаты; FastAPI вызывает существующие
сервисы Python. Все основные сценарии подключены к реальным вычислениям.

## Запуск на этом компьютере

В корне проекта дважды нажмите **start_web.cmd**. Он запускает Python-сервер
и открывает **http://127.0.0.1:8765**. Выберите лабораторную на главной странице.
Зависимости и сборка уже подготовлены.

Альтернативный запуск из терминала PyCharm:

```powershell
cd C:\Users\user\PycharmProjects\EYAZIS
.venv\Scripts\python.exe -B -m webapp
```

Сервер работает, пока открыто его окно. Для остановки нажмите Ctrl+C.
Повторный запуск открывает уже работающий экземпляр. Другой порт:
`python -B -m webapp --port 8766`. `--no-browser` оставляет запуск браузера пользователю.

## Что доступно

| Работа | Действия |
|---|---|
| №1 | Демо, загрузка URL и ручного текста, коллекция, удаление выбранных документов, BM25 и его параметры, текст/ключевые слова, экспертные оценки, метрики, графики и экспорт |
| №2 | Демо и загрузка PDF, роли train/test, EN/ES, source_id, параметры трёх методов, обучение, предсказания с объяснениями, accuracy/F1/время и отчёт |
| №3 | Демо, PDF/TXT и введённый текст, язык/область, размер реферата, TF-IDF + позиции и TextRank, ключевые слова, оценки предложений, сравнение и отчёт |
| №4 | TXT или текст EN→FR, область, перевод, частотный словарь и сохранение ручных правок, морфология, выбор предложения, деревья зависимостей и отчёт |
| №5 | Исходные WAV и загрузка файлов, подтверждённые интервалы, прослушивание диапазона, анализ, нарезка, циклы, частота/разрядность, новая запись по явной кнопке |
| №6 | Исходные и загруженные WAV, выбор фрагмента, PSOLA, постоянная/переменная скорость, таблицы контуров F0/длительности/усиления, перестановки слов, графики и WAV |
| №7 | Все восемь рецептов из подтверждённого банка, стыки 0–50 мс, эталон, результат, графики, WAV и отчёт |
| №8 | Ввод/TXT на французском, Siwis/Tom, темп, громкость, синтез, воспроизведение/пауза, WAV и отчёт |
| №9 | WAV и WER по введённому эталону, проверка команд без выполнения; явное включение микрофона, промежуточный текст и решения, редактор команд, голосовое/ручное чтение абзацев, журнал JSON/CSV/HTML |

В каждой работе есть разделы эксперимента, готовых материалов и справки.
Готовые материалы №5–7 используют личные записи на этом компьютере; после
клонирования репозитория их может не быть. Неподготовленные материалы обозначены явно.

Длительные операции выполняются по очереди в отдельном потоке. Кнопка отмены
действует между этапами; текущая операция модели или фиксированная запись микрофона
сначала завершается. Отмена не обещает отката уже сохранённых изменений словаря/коллекции.
Каждый опыт получает собственный каталог и историю. Результаты доступны после перезапуска.
Можно скачать JSON, ZIP всего опыта, открыть печатаемый HTML, прослушать/скачать WAV.
Исходные слуховые оценки №5–7 не переносятся на вновь сгенерированное аудио автоматически.

## Данные

- `webapp/work/search.sqlite3` и `lexicon.sqlite3`: при первом запуске создаются
  отдельные копии существующих баз. Дальнейшие изменения веб-версии самостоятельны.
- `webapp/work/uploads`: загруженные файлы с внутренними идентификаторами.
- `webapp/work/jobs/<id>`: параметры, результаты, исходные тексты и экспорт каждого опыта.
- `webapp/work/commands.json`: настройки голосовых команд веб-версии.
- Черновики форм сохраняются в sessionStorage текущей вкладки браузера.

Рабочие данные, записи, модели, node_modules, кэш npm и сборка не включаются в Git.
Существующие программы Tkinter и CLI остаются доступны по прежним командам.
Исходные записи и исторические отчёты не перезаписываются.

## Микрофон

№5 записывает новый WAV только по кнопке «Включить микрофон и записать».
№9 включает поток только по кнопке «Включить микрофон» и не сохраняет его аудио.
Выполнение голосовых команд включается отдельным флажком. Проверка WAV всегда
остаётся без выполнения команд.

Во время синтеза/воспроизведения чтения поток №9 приостановлен. Уход с рабочей
страницы останавливает сеанс; при потере heartbeat остановка происходит в пределах
примерно 20 секунд. Модели загружаются по необходимости. Live-команды управляют
чтением внутри открытого приложения; произвольные команды ОС не исполняются.
Автоматические проверки не включают реальный микрофон: для него требуется ручная проверка устройства.

## Установка после клонирования

Проверено на Windows, Python 3.12.6 и Node.js 24.15.0.

Установите зависимости необходимых лабораторных из их README и сервер:

```powershell
.venv\Scripts\python.exe -m pip install -r webapp/requirements-lock.txt
cd webapp/frontend
npm ci
npm run build
```

Node нужен для разработки/сборки. Обычный запуск готовой сборки использует Python
и браузер. Голоса Piper, модели Vosk, Marian и языковые модели spaCy устанавливаются
по инструкциям №3, №4, №8, №9; веса и личные записи в репозиторий не входят.
Для поиска по интернет-страницам нужна сеть; локальные расчёты выполняются без неё.

## Разработка и проверки

Backend: `python -B -m webapp --no-browser`.
Frontend в другом терминале: `cd webapp/frontend; npm run dev`.
Vite проксирует `/api` и `/files` к локальному серверу.

```powershell
.venv\Scripts\python.exe -B -m unittest webapp.tests.test_api -v
.venv\Scripts\python.exe -m ruff check webapp
.venv\Scripts\python.exe -m ruff format webapp --check
.venv\Scripts\python.exe -B -m webapp.tools.verify
```

В `webapp/frontend`: `npm run check`, `npm run build`, `npm run test:browser`.
Последняя команда требует запущенный сервер и установленный Microsoft Edge.
Она запускает реальные веб-опыты и сохраняет скриншоты в `webapp/work/browser-check`.
Микрофон не активируется.

Проверки API покрывают поиск/оценки/экспорт, загрузку, ограничения путей, внешние
источники запросов, валидацию политики, отмену и восстановление истории, нарезку WAV
и управление имитированным микрофоном. Прогон `verify` выполняет 12 реальных
сценариев всех девяти работ, проверяет отчёты/ZIP/WAV и сохранность исходных записей.

Сервер слушает только 127.0.0.1 и предназначен для одного локального пользователя.
Это общий слой представления над существующими приложениями, без переноса
вычислительной логики в браузер. Не заменяет ручную оценку качества синтеза/ASR.
