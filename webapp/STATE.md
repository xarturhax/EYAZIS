# Веб-интерфейс лабораторных: реализован, 30.10.2026

Пользователь одобрил design_preview/index.html и поручил реализовать приложение.
Цель: общий локальный FastAPI + React/TypeScript, реальные сценарии лабораторных №1–9,
отдельные рабочие пространства, сохранение/экспорт, фоновое выполнение и запускной файл.
Текущие CLI/Tkinter и личные исходники сохраняются. Новые результаты — webapp/work/.

Реализованы FastAPI-сервер, React/TypeScript-интерфейс, светлая/тёмная темы,
девять рабочих пространств, реальные вычисления, формы параметров, загрузка,
результаты, графики, аудио, история, JSON/HTML/CSV/ZIP и печать отчётов.
Табличные редакторы контуров просодики и голосовых команд; черновики в sessionStorage.

Запуск: двойной щелчок по start_web.cmd в корне либо
.venv/Scripts/python.exe -B -m webapp. Адрес http://127.0.0.1:8765.
Обычный запуск не требует Node; сборка webapp/frontend/dist уже подготовлена.
После клонирования установить серверные зависимости, зависимости/модели лабораторных
и выполнить npm ci / npm run build в webapp/frontend. Подробности README.md рядом.

Рабочие базы и команды отдельные от прежних: webapp/work/. Исходные БД копируются
при первом запуске через SQLite backup. Личные записи и исторические оценки не менялись.
Модели в одном фоновом worker; отмена между этапами. Файлы каждого опыта сохраняются
в work/jobs/<id>, запрос — request.json, ответ — result.json, состояние — state.json.
Незавершённые при остановке задачи видны после перезапуска как interrupted.

Особенность №1: исходный репозиторий инициализирует схему при каждом открытии.
Параллельные HTTP-чтения и worker-записи сериализованы через RLock веб-адаптера;
так устранена обнаруженная при повторной проверке ошибка database is locked.
Проверка конкурентных запросов добавлена в API-тесты.

Проверено:
- 12 unittest API/очереди, включая отмену, рестарт, экспорт, ограничения путей,
  конкурентные запросы, PCM-нарезку и имитированный микрофон.
- 12 реальных сценариев всех 9 адаптеров: webapp/tools/verify.py;
  сохранность 25 исходных записей подтверждена. Локальный результат:
  work/verification/f9b397f63918401b8ca14f029ce1e07b/verification.json.
- Edge/Playwright: все 9 веб-сценариев, загрузка TXT, WAV Range 206, графики,
  история, вкладки, темы, ширина 390 px, ошибок JS нет. Микрофон не активирован.
  Результат и скриншоты: work/browser-check/.
- TypeScript, production build, Prettier check, Ruff check/format прошли.

Микрофон №5 включается только явной кнопкой фиксированной записи, №9 — кнопкой
включения потока. Для №9 есть heartbeat 20 с, остановка при уходе со страницы,
пауза на время синтеза/воспроизведения. WAV-проверка не выполняет команд.
Реальное устройство микрофона в автоматическом прогоне не включалось;
его работа с новым интерфейсом остаётся пунктом ручной проверки.

Не запускать повторно старую разметку/оценки №5–7 ради переноса интерфейса.
Новые синтезированные WAV не наследуют субъективные оценки старых вариантов.
